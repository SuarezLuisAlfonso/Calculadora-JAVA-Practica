# Calculadora-JAVA-Practica
Quería practicar mi java, empezando con varios proyectos que iré subiendo, esta vez empecé con una calculadora la cual intentare convertirla en una aplicación funcional y que sirva para que las personas prefieran usarla a otras alternativas.
Release Release v0.2.0.  After creating the calculator's core logic, I started working on the frontend. For this release, I added a new graphical interface using JavaFX and Gradle, based on the design of the Windows 11 Calculator. 

At this stage, the project includes the initial graphical interface and only a few button events have been implemented. More functionality and interactions will be added in future releases.

New Features
- Added a new graphical interface using JavaFX.
- Added Gradle configuration for the JavaFX project.
- Based the interface design on the Windows 11 Calculator.
