# Calculadora-JAVA-Practica
Quería practicar mi java, empezando con varios proyectos que iré subiendo, esta vez empecé con una calculadora la cual intentare convertirla en una aplicación funciona y que sirva para que las personas prefieran usarla a otras alternativas.
Release v0.1.0. First functional implementation of the calculator. This version establishes the foundation of the project and serves as the starting point for future development, including new features, usability improvements, and codebase optimization.
New Features
- Added exponentiation support.
- Added an exit option in the main menu to terminate the program.

Changes
- Introduced initial validation for exponent values.
- Exponents are temporarily limited to non-negative integers.
- Exponents must be whole numbers (integers).
- These restrictions are temporary and will be expanded in future versions as the calculator continues to evolve.
